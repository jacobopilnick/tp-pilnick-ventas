# TP Ventas – Análisis de Datos

## Descripción
Este trabajo práctico consiste en aplicar conceptos de gestión colaborativa y control de versiones utilizando Git, GitHub y Jira.

Se analiza un conjunto de datos de ventas de forma básica, obteniendo algunos indicadores que permiten entender el desempeño general de una empresa.

---

## Escenario
Se trabajó con el Escenario B: Análisis de Ventas de una pequeña empresa.

---

- Jacobo Pilnick

## Organización del Proyecto

El repositorio está organizado en tres carpetas principales:

- datos/ --> contiene el archivo de ventas en formato CSV  
- scripts/ --> contiene el código Python utilizado para el análisis  
- resultados/ --> contiene los resultados generados  

---

## Dataset utilizado

El archivo contiene datos simples de ventas, incluyendo:

- fecha de venta  
- monto de la venta  

El objetivo es poder trabajar con estos datos para obtener métricas básicas.

---

## Objetivos del análisis

- Calcular el total de ventas  
- Analizar las ventas en el tiempo  
- Obtener información general del comportamiento de las ventas  

---

## Ejecución

Para ejecutar el proyecto:

1. Abrir el archivo analisis.py en un entorno Python.
2. Ejecutar el archivo ubicado en la carpeta /scripts.
3. Observar los resultados generados a partir del dataset de ventas.
